# XXD VPS

[中文](./README.md) · [English](./README.en.md) · [한국어](./README.ko.md) · [日本語](./README.ja.md) · [العربية](./README.ar.md) · [Español](./README.es.md) · [Français](./README.fr.md) · **Русский** · [Deutsch](./README.de.md) · [Português](./README.pt.md)

Едете в командировку в страну, где интернетом пользоваться сложно? Продолжайте пользоваться привычными сайтами и инструментами ИИ.

Сайт с пошаговым руководством (на английском и китайском): <https://vps.xiaoxiaodong.ai/en/> (китайская версия: <https://vps.xiaoxiaodong.ai>; зеркало: <https://nevertoday.github.io/xiaoxiaodong-vps/en/>)

Как это работает: вы ставите Codex на свой компьютер, покупаете зарубежный сервер, Codex удалённо настраивает его по этому проекту, а вы импортируете подписку на телефон и компьютер. **На сервер ничего устанавливать не нужно, и заходить на него тоже не нужно.** Соединение только ваше, вы не делите его с посторонними.

## Что вы получите

- **Собственное соединение** для компьютера, телефона и роутера. Есть основной и резервный узлы: если один перестаёт работать, соединение автоматически переключается на другой.
- **Работает сразу после импорта.** Правила для популярных сайтов и инструментов ИИ уже настроены. Сайты материкового Китая открываются напрямую, всё остальное идёт через ваш сервер.
- **CLIProxyAPI**: собственный API и панель управления, которые сами обновляются до последней версии.
  - ⚠️ **Не подключайте аккаунт Claude к CLIProxyAPI**: политика Anthropic это запрещает. OpenAI официально разрешает так использовать аккаунты ChatGPT — я сам очень люблю делать с его помощью картинки.
- **Безопасность**: на сервер можно войти только с ключом с вашего компьютера, а настоящий HTTPS-сертификат избавляет от предупреждения «небезопасно» в браузере.
- **Почти без обслуживания**: сертификаты, правила и CLIProxyAPI обновляются сами, конфигурация резервируется каждый день.

## Четыре шага

### 1. Установите Codex на компьютер

Codex — это ИИ-приложение от OpenAI; входить в него нужно с платным тарифом ChatGPT. Оно ставится на **ваш собственный компьютер**, а не на сервер.

- **Новичкам**: установите приложение для компьютера. В Windows найдите **Codex** в Microsoft Store и установите; на Mac скачайте его с [сайта Codex](https://openai.com/codex/). Откройте и войдите в свой аккаунт ChatGPT.
- **Опытным**: используйте [Codex](https://github.com/openai/codex) в командной строке. Уже установлен? Запустите `codex` в терминале и просто общайтесь с ним.

Нет тарифа ChatGPT? На [сайте с руководством](https://vps.xiaoxiaodong.ai/en/guide/3-deploy/) в шаге 3 есть вариант «Type it yourself» (ввести всё самому).

### 2. Купите сервер

Сейчас берите **BandwagonHost** — я и сам им пользуюсь.

Я советую именно такие серверы, потому что **этот урок оплачен моими деньгами и набитыми шишками**: их маршруты оптимизированы для подключения из материкового Китая, и работают они так стабильно, что теперь я их преданный фанат.

**[Купить BandwagonHost](https://bandwagonhost.com/aff.php?aff=83651&a=add&pid=88&billingcycle=quarterly&configoption%5B17%5D=55)**

Тариф по этой ссылке включает **2 ТБ трафика в месяц** и 2 ГБ памяти, дата-центр CN2 GIA в Лос-Анджелесе — с запасом хватит вам и вашей семье.

Выберите систему **Ubuntu 24.04**. Когда сервер будет готов, запишите из панели управления три вещи: **IP сервера, пароль root (или файл ключа) и порт SSH**. Если это BandwagonHost, запишите ещё **VEID и API Key** (страница «API» в левом меню KiwiVM, [как найти](https://vps.xiaoxiaodong.ai/en/howto/traffic-and-ip/)), чтобы трафик в приложениях совпадал с панелью.

После покупки заходить на сервер и что-то на него ставить не нужно — следующий шаг сделает Codex.

### 3. Поручите настройку Codex

Откройте Codex из шага 1 (подойдёт и любой другой инструмент ИИ, который умеет выполнять команды на вашем компьютере). Скопируйте текст ниже, заполните и отправьте:

```text
Пожалуйста, настрой мой новый сервер по схеме «XXD VPS».

Схема: https://github.com/nevertoday/xiaoxiaodong-vps
Сначала скачай этот проект на мой компьютер и полностью прочитай
skills/xiaoxiaodong-vps/SKILL.md. Строго следуй его шагам и правилам
и используй скрипты проекта для настройки и проверки.
Общайся со мной по-русски, пожалуйста.

Мой сервер:
- IP:
- Вход: начальный пароль (дай мне самому его ввести; не проси присылать его в чат)
- Пользователь и порт SSH: по умолчанию
- Имя, под которым я хочу входить: bwg
- VEID и API Key BandwagonHost (для официального расхода трафика; если это не BandwagonHost, удалите эту строку):
```

Что заполнить:

- **IP**: IP сервера из панели управления.
- **Вход**: если провайдер выдал файл ключа, замените на `файл ключа: путь к файлу` (подойдёт и zip).
- **Имя**: замените `bwg` на любое имя. Потом достаточно набрать `ssh это-имя`, чтобы войти на сервер.
- **BandwagonHost**: впишите VEID и API Key в последнюю строку. Тогда приложения берут лимит трафика, расход и день сброса прямо из BandwagonHost — и для тарифа на 1 ТБ, и для 2 ТБ цифры совпадут. **Не BandwagonHost? Удалите эту строку**; тогда расход показывается из расчёта 1000 ГБ в месяц.

Если пользователь и порт не root / 22, замените «по умолчанию» на настоящие значения.

Дальше просто дождитесь, пока ИИ закончит, обычно 10–20 минут. В какой-то момент на вашем компьютере появится окно для пароля — введите в него пароль сервера один раз. **Никогда не вставляйте пароль в чат.** После настройки вход по паролю отключается, и войти можно только с этого компьютера.

Если ИИ не может скачать проект, [скачайте ZIP](https://github.com/nevertoday/xiaoxiaodong-vps/archive/refs/heads/main.zip) сами, распакуйте и добавьте в текст строку: «Проект уже лежит здесь: путь к папке».

По завершении на рабочем столе появится файл `my-server-ваше-имя-subscriptions-and-accounts-ru.md`, в нём:

- **адрес подписки Clash** для компьютера и роутера и **адрес подписки Shadowrocket** для iPhone;
- адрес, имя пользователя и пароль панели 3x-ui;
- адрес панели CLIProxyAPI, ключ входа в неё, адрес API и ключ API.

### 4. Импортируйте подписку

- **Компьютер (рекомендуем Clash Verge Rev)**: установите [Clash Verge Rev](https://github.com/clash-verge-rev/clash-verge-rev/releases), импортируйте адрес подписки Clash, выберите режим **Правила (Rule)** и включите **режим TUN** (виртуальный сетевой адаптер; при запросе установите службу). Если включён только системный прокси, WebRTC в браузере может раскрыть ваш настоящий IP — см. [руководство по устранению утечки WebRTC](./docs/Clash-Verge-WebRTC泄露修复手册.md) (на китайском, написано так, чтобы ИИ-ассистент мог выполнить его шаг за шагом).
- **iPhone**: импортируйте адрес подписки Shadowrocket в Shadowrocket.
- **Роутер (OpenClash)**: подходит тот же адрес подписки Clash, и через линию идут все домашние устройства. Добавьте его в подписке конфигурации (не загружайте YAML-файл, иначе не будет видно расход трафика и правила не будут обновляться), выключите онлайн-конвертацию подписки и используйте ядро Meta.
- **Уже пользуетесь v2rayN (Windows / Mac / Linux)**: работает, но только как запасной вариант. Импортируйте адрес из строки «Shadowrocket (iPhone)» (не из строки Clash), выберите маршрутизацию «в обход материкового Китая» и включите TUN против утечек WebRTC. В этой подписке только узлы, без правил для ИИ и прямого WeChat, поэтому на компьютере по-прежнему рекомендуем Clash Verge Rev. См. [инструкцию по v2rayN](https://vps.xiaoxiaodong.ai/en/howto/v2rayn/) (на английском).

Затем откройте <https://ip.net.coffee/claude/>. Если там отображается IP вашего сервера, всё подключено.

## Перед поездкой

- **Всё настройте и проверьте до отъезда.** В сети с ограничениями скачать проект или даже открыть инструменты ИИ может стать намного сложнее.
- Установите клиенты и импортируйте подписки и на телефон, и на компьютер, проверьте, что подключаются оба узла.
- Если какая-то местная сеть не достаёт до сервера, сначала попробуйте другую (Wi-Fi в отеле, мобильный интернет, другой оператор). Если не работает ни одна, скорее всего, IP сервера там заблокирован. Настройками это не исправить — попросите у провайдера новый IP.
- Пользуйтесь соединением только сами и с семьёй, никому его не передавайте.

## Конфиденциальность

- В проекте нет никакой информации о реальных серверах.
- Пароли, ключи, адреса подписок и ключи API каждого сервера создаются заново при настройке и хранятся только на сервере и на вашем компьютере. ИИ не показывает их в чате.
- Нигде не публикуйте файл с данными для входа, адреса подписок и ключи и не делайте их скриншоты.
- О проблемах безопасности сообщайте по [SECURITY.md](./SECURITY.md).

Получится ли подключиться и с какой скоростью, зависит ещё и от местной сети и маршрута до сервера. Проект гарантирует правильную настройку сервера, но не то, что один и тот же IP будет доступен из любой страны и у любого оператора.
