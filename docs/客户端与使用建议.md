# 客户端与使用建议

## 电脑：Clash Verge Rev

Windows、macOS、Linux 都推荐 **Clash Verge Rev**。规则和 AI 分流已经写在订阅里，客户端只需要导入。

- 项目主页：<https://github.com/clash-verge-rev/clash-verge-rev>
- 下载：<https://github.com/clash-verge-rev/clash-verge-rev/releases>（按系统和 CPU 选择安装包）

设置步骤：

1. 打开 **订阅 / Profiles**，粘贴登录信息文件里的 **Clash 订阅地址**，保存并更新；
2. 选中刚导入的订阅；
3. 运行模式选 **规则 / Rule**；
4. 打开 **系统代理 / System Proxy**。

先不要开全局、直连或 TUN 模式。只有某个程序不走系统代理时，再单独考虑 TUN 模式。

订阅里有两个节点：`名称-Reality` 是主力，`名称-TLS` 是备用。`AUTO-自动切换` 会在主力不通时自动换到备用；`AI-人工智能` 分组可以单独指定 AI 网站走哪个节点。

> 旧版 Clash for Windows 不支持这份订阅，会报 `cannot unmarshal !!seq into string`，请换成 Clash Verge Rev。
> 不要把 Shadowrocket 的订阅地址填进 Clash Verge Rev，两者格式不同。

## iPhone：Shadowrocket

在 Shadowrocket 里添加订阅，粘贴 **Shadowrocket 订阅地址**，更新后选择节点即可。Shadowrocket 用的是单独的一套身份，和电脑端互不影响。

## 路由器：OpenClash

在 OpenClash 的配置订阅里添加 **Clash 订阅地址**。规则文件从你自己的服务器下载，路由器不需要能直连 GitHub。

## 检查出口

打开 <https://ip.net.coffee/claude/>，先确认页面检测到的是你 VPS 的 IP，再看评分。**70 分以上**相对安心；这是第三方参考，不代表 Claude 官方的判断。

分数低时可以让 AI 排查：IP 黑名单和历史、机房类型、DNS 泄漏、IPv6 暴露、是否有旧订阅或别人在用。问题出在 IP 本身时，配置调得再好也有限，换 IP 更有效。

## 使用习惯

- 按隐私需要关闭电脑不必要的**定位权限**。这不会改变出口 IP，也不是绕过风控的手段。
- 长期固定用某台 VPS 时，可以把电脑**时区设成 VPS 所在地区**，并尽量不要频繁来回切换。
- 保持系统语言、浏览器、登录设备相对稳定，避免短时间内在多个国家、多个节点、多个账号之间来回切。
- **不要问违规的问题**：不提交违法、暴力伤害、恶意入侵、窃取隐私或其他违背人类基本价值观的内容，遵守所在地法律和 AI 服务的使用政策。
- **避免批量化使用**：不要短时间内大量提相似的问题、并发刷请求、自动化轮询、批量导出，或做类似"模型蒸馏厂"的事情。确实有批量需求，请使用官方 API 并合理限速。
- 不要把自己的账号做成公共接口，也不要把节点大范围分享给陌生人。
