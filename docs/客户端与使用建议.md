# 客户端与使用建议

## 电脑：Clash Verge Rev

Windows、macOS、Linux 都用 **Clash Verge Rev**：[下载页面](https://github.com/clash-verge-rev/clash-verge-rev/releases)，按自己的系统和 CPU 选安装包。

1. 打开 **订阅**，粘贴登录信息文件里的 **Clash 订阅地址**，保存；
2. 选中刚导入的订阅；
3. 模式选 **规则**；
4. 打开 **系统代理**。

不用开全局或 TUN 模式。只有某个软件不走系统代理时，再单独打开 TUN。

订阅里有两个节点：`名字-Reality` 是主力，`名字-TLS` 是备用。`AUTO-自动切换` 会在主力不通时换到备用。`AI-人工智能` 分组可以单独指定 AI 工具走哪个节点。

常见问题：

- 旧版 Clash for Windows 打不开这份订阅（报 `cannot unmarshal !!seq into string`），换成 Clash Verge Rev。
- Shadowrocket 的订阅地址不能填进 Clash Verge Rev，两者格式不同。

## iPhone：Shadowrocket

添加订阅，粘贴 **Shadowrocket 订阅地址**，更新后选节点即可。

## 路由器：OpenClash

在 OpenClash 里添加 **Clash 订阅地址**。规则文件从你自己的服务器下载，路由器不需要能访问 GitHub。

## 怎么确认通了

打开 <https://ipinfo.io>，显示的是你服务器的 IP 和所在地，就说明流量已经走你的线路。

## 使用习惯

- 长期用同一台服务器时，可以把电脑时区设成服务器所在地，少在不同国家的节点之间来回切。
- 不需要的定位权限可以关掉。
- 遵守当地法律和各个网站、AI 工具的使用规定，不要提交违法或伤害他人的内容。
- 不要用脚本短时间大量刷请求或批量提问，有批量需求请用官方 API。
- 线路只给自己和家人用，不要分享出去。
