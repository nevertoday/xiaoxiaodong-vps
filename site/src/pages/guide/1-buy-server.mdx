## 配置怎么选

商家的页面上选项很多，只看下面这几项就够了：

| 选项 | 选什么 | 为什么 |
|---|---|---|
| 操作系统 | **Ubuntu 24.04** | 方案只支持 <Term k="Ubuntu" /> 22.04 以上和 Debian 12 以上。选错了，要到后台重装 |
| 机房位置 | 美国洛杉矶 | 离国内近，主流 AI 服务都支持美国 |
| 内存 | 1G 就够 | 节点和 AI 接口在 1G 内存的机器上实测运行良好 |
| 虚拟化 | <Term k="KVM" /> | 能装完整的系统。搬瓦工默认就是 |
| IP | 独立的 <Term k="公网 IP" />（IPv4） | 不能是 <Term k="NAT" /> 机器，那种只给几个端口，证书和节点装不上 |
| 流量 | 每月几百 G 到 1T | 个人和家人日常使用足够；推荐的搬瓦工套餐是每月 2T |

<Callout type="warn" title="系统一定要选对">
最常见的错误是系统选成了 CentOS 或其他旧系统。这套方案装不上，只能到商家后台「重装系统」改成 Ubuntu 24.04。重装以后 root 密码通常会变，要用新的。
</Callout>

## 记下三样东西

在开通邮件或商家后台里找到这三样，抄到一个只有你能看到的地方：

| 记下来 | 长什么样 | 说明 |
|---|---|---|
| 服务器 IP | 四组数字，比如 `203.0.113.10` | 服务器的门牌号 |
| <Term k="root" /> 密码 | 一串字母和数字 | 管理员密码。有的商家给的是密钥文件，那就记下文件放在哪 |
| <Term k="SSH" /> <Term k="端口" text="端口" /> | 多数是 `22`，有的商家是别的数字 | 远程登录用的「房间号」 |

<Callout type="ok">
商家后台里这台服务器的状态是「运行中」（Running），并且你已经记下了 IP、root 密码、SSH 端口。
</Callout>

<Callout type="no">
不要把这三样发到群里、发给陌生人，也不要截图分享。下一步配置好以后，服务器会改成只能用你电脑上的密钥登录，密码就不能用来远程登录了。
</Callout>

## 卡住了？

<Q q="付款失败怎么办？">
先换一种结账页上支持的付款方式再试。还是不行，就给商家开工单问一下；也可以换一家商家。
</Q>
<Q q="付款成功了，但一直没收到开通邮件？">
先看邮箱的垃圾箱。再登录商家后台，找「我的服务」（My Services）之类的列表，IP 和登录信息一般在那里也能看到。新账号偶尔会被人工审核，等一等或者开工单问。
</Q>
<Q q="系统选错了，或者我不确定选了什么？">
到商家后台找「重装系统」（Reinstall OS），选 Ubuntu 24.04。重装会清空服务器，刚买的机器没什么可丢的。重装后用新的 root 密码。
</Q>
<Q q="SSH 端口不是 22，有关系吗？">
没关系，记下来，下一步告诉 AI（或者填进命令里）就行。
</Q>
