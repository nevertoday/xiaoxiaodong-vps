搬瓦工的后台分两层：**客户中心**（下单、付款、续费）和 **KiwiVM 控制面板**（管理这台服务器）。下面的按钮名称以英文界面为准，商家改版后可能略有不同。

## 1. 下单

1. 打开 [搬瓦工购买链接](https://bandwagonhost.com/aff.php?aff=83651&a=add&pid=88&billingcycle=quarterly&configoption%5B17%5D=55)（作者的邀请链接，见下面说明）。原来推荐的 1T 套餐现在缺货，不用等。
2. 确认套餐（链接里的套餐每月 2T 流量、2G 内存）、付款周期（Billing Cycle），机房（Location）选**洛杉矶**相关的选项。
3. 点加入购物车，结账时注册账号（推荐用 Gmail），付款方式可以选**支付宝**（Alipay）。

## 2. 进入 KiwiVM 控制面板

1. 登录搬瓦工客户中心，进入 Services → My Services，能看到刚买的服务器。
2. 点进去，找到 **KiwiVM Control Panel** 的入口，打开。

## 3. 找到要记下的三样东西

- **IP 地址**和 **SSH 端口**：KiwiVM 首页（Main controls）就有显示。搬瓦工的 SSH 端口**不一定是 22**，以页面为准。
- **root 密码**：开通邮件里会给；找不到的话，在 KiwiVM 里用「Root password modification」生成一个新的（会显示一次，马上抄下来）。
- **VEID 和 API Key**（可选，建议记下）：在 KiwiVM 左侧菜单的 **API** 页。部署时一起告诉 AI，客户端里的流量额度、已用量和重置日就直接读后台，1T、2T 套餐都对得上。怎么找见 [查看流量](/howto/traffic-and-ip/)。

## 4. 确认系统

KiwiVM 首页的 Operating system 一栏就是当前系统。搬瓦工开通时装的是默认系统，多半要重装一次：先在首页点 **Stop** 关机，再点左侧 **Install new OS**，选 Ubuntu 24.04，勾选同意后点 **Reload**，几分钟后抄下页面显示的新 root 密码和 SSH 端口。每一步的细节见 [后台重装系统为 Ubuntu](/howto/reinstall-os/)。

<Callout type="ok">
KiwiVM 里服务器状态是运行中（Running），你已经记下了 IP、SSH 端口和 root 密码，系统是 Ubuntu 24.04。
</Callout>

<Callout type="warn">
搬瓦工的服务器出厂时可能已经开了自己的防火墙或别的设置，不用管，第 3 步的脚本会按方案重新配置。
</Callout>
