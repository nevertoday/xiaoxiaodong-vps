## 需要什么

- ChatGPT 的付费账号（Plus、Pro、Business、Edu、Enterprise 等），也可以用 API Key；
- 在 OpenAI 支持的国家和地区使用；

<Callout type="tip" title="不习惯终端？Windows 用户？">
用 Codex 桌面版就行：Windows 在微软商店搜 Codex 安装，Mac 到官网下载，见 [第 1 步「在电脑上装 AI」](/guide/1-ai-assistant/)。这一页是给习惯在 Mac 终端里用命令行的人的。
</Callout>

## 1. 安装

在**你自己电脑**的终端里（不是服务器上）粘贴这条命令，回车：

<Copy id="cx" lang="bash" title="安装 Codex（Mac）" code="curl -fsSL https://chatgpt.com/codex/install.sh | sh" />

Mac 用 Homebrew 的也可以运行 <Cmd c="brew install --cask codex" />。装好后**关掉终端，重新打开**，检查：

<Copy id="cx-v" lang="bash" title="检查版本" code="codex --version" />

## 2. 登录

在终端里输入 `codex`，回车，选择 **Sign in with ChatGPT**，在浏览器里登录你的 ChatGPT 账号并授权。

<Callout type="ok">
终端里出现 Codex 的对话界面，可以输入问题。
</Callout>

## 卡住了？

<Q q="提示 codex: command not found？">
重新打开终端再试。还不行，到 [Codex 官方仓库](https://github.com/openai/codex) 看最新的安装说明。
</Q>
<Q q="浏览器没有自动打开？">
登录界面里有设备码（device code）方式：在浏览器里打开它给的网址，输入页面给出的代码即可。
</Q>
