## 有什么用

装成 skill 以后，不用每次复制一大段话。直接对 AI 说「用 xiaoxiaodong-vps 帮我配置新买的服务器」，它会自己问你要服务器信息。

**第一次用可以不装**：第 3 步那段话会让 AI 自己下载方案。

## 安装

在终端里运行一次：

<Copy id="skill" lang="bash" title="下载方案并装成 skill" code={`git clone https://github.com/nevertoday/xiaoxiaodong-vps.git
mkdir -p ~/.claude/skills ~/.codex/skills
cp -R xiaoxiaodong-vps/skills/xiaoxiaodong-vps ~/.claude/skills/
cp -R xiaoxiaodong-vps/skills/xiaoxiaodong-vps ~/.codex/skills/`} />

只用其中一个 AI 助手的话，另一行 `cp` 不运行也行。

## 以后怎么更新

方案有更新时，进入下载的目录拉取最新版，再复制一次：

<Copy id="skill-up" lang="bash" title="更新 skill" code={`cd xiaoxiaodong-vps && git pull && cd ..
cp -R xiaoxiaodong-vps/skills/xiaoxiaodong-vps ~/.claude/skills/
cp -R xiaoxiaodong-vps/skills/xiaoxiaodong-vps ~/.codex/skills/`} />

<Callout type="ok">
重新打开 AI 助手，说「用 xiaoxiaodong-vps 帮我检查服务器」，它能认出这个 skill。
</Callout>
