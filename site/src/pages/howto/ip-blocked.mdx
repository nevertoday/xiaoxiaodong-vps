## 先确认是不是被墙了

IP 被墙的典型样子：

- 换了几种网络（手机流量、别的 Wi-Fi、不同运营商）都连不上，两个节点都不行；
- 让 AI 给服务器体检，一切正常；在境外（或者用别的梯子）能正常登录服务器；
- 常见的是 **ping 得通，但所有端口都连不上**（只封了 TCP）；也有 ping 都不通的。

想自己确认（服务器要已经按本教程配置好）：在浏览器打开 `https://tcp.ping.pe/服务器IP:443`，再把 `:443` 换成 `:22` 测一次。表格最下面 `China` 开头的几行里，**只看 ISP 是 China Telecom、China Unicom、China Mobile 的那 6 行**：它们都是 `failed`，而其他国家都是 `successful`，基本就是被墙了。ISP 是 Tencent 的几行别看，测 22 端口时正常的 IP 也会 failed。

还没配置的服务器别用这个方法判断：443 端口要配置完才有程序在接听，没人接听的端口全世界都会显示 failed，测不出是不是被墙。

也可以用 [itdog.cn 的 TCPing](https://www.itdog.cn/tcping/)，国内测试点更多：国内大部分测试点都超时、而服务器体检正常，同样说明被墙了。

<Callout type="warn">
换 IP 之前，先排除自己这边的问题：电脑上其他 VPN、加速器关掉没有，客户端是不是用的最新订阅。只是个别网络连不上、换个网络就好，一般不是被墙。
</Callout>

## 换 IP 的办法

<Tabs id="vendor" label="选商家" items={[["bwg", "搬瓦工"], ["dmit", "DMIT"]]}>
<div slot="bwg">

### 推荐：直接付费换 IP

大多数情况直接付费换掉最省事。

1. 登录搬瓦工官网，打开 [Request IP Change](https://bandwagonhost.com/ipchange.php) 页面（要先登录）。
2. 选这台服务器，按页面提示付费申请。价格以页面上显示的为准。
3. 等搬瓦工换好，新 IP 会显示在 KiwiVM 控制面板首页。

- **换 IP 的钱不退**：搬瓦工的服务条款写明，退款时不退换 IP 的费用。
- **「机房迁移」这时用不了**：迁到别的机房也会换 IP，但条款写明，IP 在黑名单上时不能用 Datacenter Migration，要等它连续 7 天不在任何黑名单上。

### 例外：买了不到一个月、流量也没怎么用，可以退掉重买

新买的服务器会分到新的 IP，还能省下换 IP 的钱。但只有**同时满足**搬瓦工 30 天退款的这些条件才值得试，不满足就直接付费换 IP（以[服务条款](https://bandwagonhost.com/terms-of-service.php)为准）：

- 是新订单（续费的不行），下单不超过 30 天；
- 这个月用的流量**不到套餐额度的 10%**（1T 的套餐就是 100G 以内）；
- 没有欠费、没有违反条款、没有拒付过；
- 分到的 IP 不在任何黑名单或封锁名单（blocklist）上，也没有因为上黑名单被换过 IP。

最后一条要注意：条款写明 IP 上了黑名单就不退款，但没说「被墙」算不算，**以搬瓦工客服的答复为准**。符合条件想试的话，**先申请退款，被拒了再付费换 IP**；先换了 IP 再申请，就不符合条件了。

退款步骤和可以直接复制的邮件见 [退掉服务器、重新买一台](/howto/refund-rebuy/)。

</div>
<div slot="dmit">

DMIT 的规则写在 [官方文档](https://docs.dmit.io/zh/guide/faq/ip) 里，按套餐系列不同：

- **刚开通，分到的 IP 就是被墙的**：提交工单，免费换。
- **Pro、EB 系列**：下面四条**同时满足**就免费换，否则付费 5 美元（两次之间至少隔 7 天）：
  - 买了满 7 天（第 8 天起）；
  - 距上次换 IP 至少 15 天；
  - ICMP 和所有 TCP 端口都被封。**ping 还通、只封了 TCP 的不算**，要付费；
  - 服务剩余有效期至少 7 天。
- **T1 系列**：只能付费，每次 5 美元。要开通满 24 小时、距上次换 IP 至少 3 天、剩余有效期至少 3 天。

怎么申请：

- 在 DMIT 客户中心**提交工单**申请，写明服务器和「需要更换 IP」。
- 付款并换好以后，不能撤回、不能退款。新 IP 是随机分配的。
- 频繁申请可能被禁止使用换 IP 功能。

</div>
</Tabs>

<Callout type="warn">
新 IP 也可能再被墙，没有人能保证。别把订阅分享给外人，用的人越多、流量越杂，越容易出问题。
</Callout>

## 换完 IP 以后

方案部署时，证书、订阅地址和节点都和 IP 绑在一起。配置工具发现服务器 IP 变了会直接停下，不会在旧配置上硬改，所以换完 IP 要**从头配置一次**：

1. 在商家后台重装系统，见 [后台重装系统为 Ubuntu](/howto/reinstall-os/)。
2. 用新 IP 从 [第 3 步「配置服务器」](/guide/3-deploy/) 重新开始，**起一个新的 ssh 名字**（旧名字还指向旧 IP，方案不会覆盖它）。
3. 在所有设备上**删掉旧订阅、导入新订阅**（订阅地址里的 IP 变了）。
4. 按 [第 5 步](/guide/5-verify/) 检查一遍，能正常上网就说明新 IP 在国内能连上。新 IP 的 Claude AI 信任评分也要重新看。
5. 搬瓦工之前接过 KiwiVM 流量显示的，按 [查看流量](/howto/traffic-and-ip/) 再接一次。

<Callout type="ok">
新 IP 在国内能连上，重新部署完成，所有设备导入了新订阅，第 5 步检查都通过。
</Callout>

<Q q="ping 得通，为什么还说被墙了？">
常见的封锁只拦 TCP 连接，ping 用的 ICMP 不受影响。所以 ping 通不代表能用，要看端口能不能连上（用上面的 TCPing 测 443）。
</Q>

<Q q="被墙之后过几天会自己恢复吗？">
有时会，但说不准要多久，也可能一直不恢复。急着用就直接换 IP。
</Q>
