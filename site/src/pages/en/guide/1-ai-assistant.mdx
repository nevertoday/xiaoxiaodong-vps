## What this step is

Install Codex (OpenAI's AI app; you sign in with your ChatGPT account) **on your own computer**. When you configure the server in step 3, you just talk to it: it runs commands on your computer and sets the server up remotely.

<Callout type="warn" title="This step has nothing to do with the server">
You don't have a server yet, and you don't need one. Codex lives on your own computer, and you'll never need to log in to the server to install anything.
</Callout>

## Beginner or experienced?

- **Beginners**: install the Codex desktop app — like installing any other app, no terminal involved. See "Install Codex" below.
- **Experienced users**: use the Codex command line. Already installed? Run `codex` in your terminal and just talk to it — in step 3, paste the message in. Not installed yet? See [Install the Codex CLI](/en/howto/install-codex/).

## Already have an AI tool? Test it first

Send it this:

<Copy id="ai-test" title="Test message for the AI" code="Please run whoami on my computer and tell me the result." />

- **It actually ran it and answered with a username**: it works — go straight to the next step.
- **It asks you to run it yourself, or says it can't**: it can only chat (chat in a web page or a phone app works this way), so it can't set things up for you. Install Codex as below.

## Install Codex (beginners)

Codex is an ordinary desktop app: download, install, sign in. It needs a paid ChatGPT plan such as Plus, Pro or Business.

<Callout type="warn">
ChatGPT is only available in the countries and regions OpenAI supports. If you can't use it yet, take the manual route for now and install Codex later.
</Callout>

<Tabs id="ai" label="Your computer" items={[["win", "Windows"], ["mac", "Mac"]]}>
<div slot="win">

1. **Install**: open the **Microsoft Store**, search for **Codex** and click "Install".
2. **Sign in**: open Codex, choose "Sign in with ChatGPT", then sign in and authorize in the browser.
3. **Pick a folder**: the first time, it asks for a working folder. Create one on your desktop (for example `vps`) and pick it.

</div>
<div slot="mac">

1. **Install**: download the Mac version from the [Codex website](https://openai.com/codex/) and drag it into Applications.
2. **Sign in**: open Codex, choose "Sign in with ChatGPT", then sign in and authorize in the browser.
3. **Pick a folder**: the first time, it asks for a working folder. Create one on your desktop (for example `vps`) and pick it.

</div>
</Tabs>

Once it's installed, send it the test message above. Before running its first command, Codex asks you to click "Allow" or "Approve" — that's normal, allow it.

<Callout type="ok">
It actually ran `whoami` and answered with a username.
</Callout>

## Not using AI: skip this step

Not planning to use AI, or no ChatGPT plan? Go straight to the next step and buy a server, then choose "Type it yourself" in step 3.

## Optional: install it as a skill

If you set up servers often, install this setup as a Codex skill; afterwards one sentence — "use xiaoxiaodong-vps to configure my new server" — is enough. You don't need it the first time: the message in step 3 has the AI download the setup itself. See [Install the xiaoxiaodong-vps skill](/en/howto/install-skill/).

## Stuck?

<Q q="During the test it told me to run the command myself?">
You're using a chat-only AI (a web page or phone app). Install Codex as above and test again inside Codex.
</Q>
<Q q="Can't find Codex in the Microsoft Store, or the Store won't open?">
Download the installer from the [Codex website](https://openai.com/codex/) and double-click it.
</Q>
<Q q="While configuring, Codex wants to install Git and Windows asks “Allow?”">
Click "Yes". On Windows the setup scripts need tools that come with Git; Codex installs them itself — on your computer, not on the server.
</Q>
