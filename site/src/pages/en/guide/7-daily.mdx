## Congratulations — the main guide is done

Once configured, the server basically runs itself: the certificate is checked every 6 hours and renewed before it expires, routing rules update daily, the AI API updates itself, and the configuration is backed up daily (7 copies kept).

This page covers everyday habits and what to do when something goes wrong.

## One small security task first

Change the root password in the provider's dashboard (see [Change the root password](/en/howto/root-password-vnc/)). The server no longer accepts passwords for remote login, but the provider's rescue console may still accept it — and it appeared in the server-ready email.

## Everyday use

- **Computer**: keep Clash Verge running, in Rule mode with Tun Mode on.
- **Phone**: turn on Shadowrocket's switch when needed.
- **Nodes**: normally use `name-Reality`; if it fails, the app's "auto switch" moves to `name-TLS`, or pick it yourself.
- **Updating the subscription**: apps refresh it automatically. If you hear the setup's rules were updated, tap "Update" once.
- **Switch less**: stick to the same server rather than hopping between countries — friendlier for AI accounts.

## When something breaks, check in this order

1. **Try another network**: mobile data, other Wi-Fi. If only one network fails, the problem is that network.
2. **Try the other node**: pick it manually in the app.
3. **Health-check the server** as above and see which item fails.
4. **Everything passes but it still won't connect**: the IP is probably blocked in mainland China. BandwagonHost and DMIT can both give you a new one; afterwards, reinstall the OS and set the server up again. See [IP blocked in China](/en/howto/ip-blocked/).

## Traffic and renewals

- **Traffic**: see this month's usage in the provider's dashboard. The apps show it too (against 1 TB a month, resetting on the provisioning day, by default). Speed tests eat traffic — don't run them often.
- **Renewal**: turn on auto-renew in the provider's dashboard or put the expiry date in your calendar. An expired server is suspended, then deleted, and its IP reclaimed.

## Setting up another server

Want a second server (a backup, or for another region)? Go through the guide again from step 2, "Buy a server" (Codex is already installed) — much faster the second time. Every server gets its own passwords, keys and subscription URLs.

## Stuck?

<Q q="New computer — how do I keep managing the server?">
The key lives in `~/.ssh/xxd-vps/your-name/` on the old computer. The simplest way is to copy that folder and the matching block in `~/.ssh/config` to the new one. Old computer gone? Log in through the provider's rescue console and ask AI to help add the new computer's key.
</Q>
<Q q="Can I install other things on the server?">
Yes, but avoid the <Term k="端口" text="ports" /> this setup uses (22, 80, 443, 2443, 2096, 8318, 53998) and allow the new service's port in the firewall. Ask AI first whether it might conflict.
</Q>
<Q q="How do I stop using it?">
Cancel renewal or delete the server in the provider's dashboard, and remove the subscription from your apps.
</Q>
