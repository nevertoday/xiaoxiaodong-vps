## Can't connect after you arrive

1. Try other networks first: hotel Wi-Fi, mobile data, a SIM from another carrier.
2. Switch to the other node in the app.
3. Still nothing? The IP is probably blocked: ask the provider for a new IP, then reinstall the OS and set the server up again (see [IP blocked in China](/en/howto/ip-blocked/)).

<Callout type="tip">
If you travel often, keep a second server from a different provider and data center as a backup — just run the main guide again from step 2, "Buy a server".
</Callout>
