DMIT is another one the author really likes using. Its routes are good, but popular plans are often out of stock. **If you can't buy, don't wait** — go with [BandwagonHost](/en/howto/buy-bandwagonhost/).

## 1. Order

1. Open [DMIT](https://www.dmit.io/aff.php?aff=23544) (the author's referral link; commission goes to charitable work; prices and stock as shown on the official site).
2. Choose a location — usually **Los Angeles** (LAX).
3. Choose a plan and billing cycle. If the order page lets you pick an OS, choose **Ubuntu 24.04**.
4. Create an account and pay.

## 2. Find the server details

1. Log in to the DMIT client area, open "My Services" (or similar) and click the new server.
2. On the server page find the **IP address** and **root password** (or a "show password" button). The SSH port is usually 22.
3. The same page usually has Reinstall, Reset Password and Console / VNC buttons you'll use later.

<Callout type="ok">
The server is running; you've written down the IP, root password and SSH port; the OS is Ubuntu 22.04+ or Debian 12+.
</Callout>
